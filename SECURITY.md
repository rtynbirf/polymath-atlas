# Безопасность

Нашли уязвимость — не открывайте публичный issue.
Откройте вкладку **Security → Report a vulnerability** этого репозитория: сообщение увидит только владелец.

Поддерживается последняя версия из ветки `main` и последний релиз. Ответ — по возможности быстро, без гарантий по срокам.

Токены и секреты в коде не храним; если нашли — сообщите тем же способом.
